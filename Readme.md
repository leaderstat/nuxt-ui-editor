Аккордион
Панель-1 - Исходный докуммент и путь с названием к нему
Панель-2 - Докуммент из загруженных в папку review начиная с Первого из списка найденных в папке. Кнопка листать Верх-Вниз выгружает из Панели-2 окна чата документ и загружает следующий по списку.
editor-toolbar содержит кнопки с функционалом - Начать ревизию документа по заданным фильтрам (У самого низа реализовать Аккордеон с Фильтрами слов быстрое добавление , редактирование списка слов для фильтра) Фильтрами замен - по-умолчанию вкл-выкл функцию поиска задвоенных, затроенных символов (исключая точку .)
Кнопка Убрать зелёное - ищет HASH, HASH-LALF даже в документах с перепутанными строками
убрать все зелёные символы (убрать все символы совпадающие по строкам с соспадающими в исходном документе)
Перед анализом после загрузки документа в чат перевести принудительно все символы в UTF-8
При анализе документов в sqlite класть HASH code каждой строки - сумма ASCII симола в utf-8 каждой строки и HASH-HALF посчитать половину строки и провести хэширование строго от начала и до середины.


Реализовать подсветку
В Панели 2
Окрашивание цветом Фон панели - чёрный - угольно-серый
- зелёный - полное совпадение HASH
 - жёлтый - совпадает только HASH-HALF
 - красный - нет совпадений HASH или HASH-HALF
